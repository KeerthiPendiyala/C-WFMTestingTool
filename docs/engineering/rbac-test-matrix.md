# RBAC Test Matrix

This maintained matrix covers `RBAC-01` through `RBAC-04` and is expanded as workflow APIs are added. Server-side authorization is authoritative; frontend capability rendering mirrors these policies only for usability. For assignment-scoped users, explicit project permissions are the source of truth. A project-level `VIEW` permission grants visibility to all suites, cycles, requirements, and test cases in that assigned project; suite/cycle scopes are a fallback only when project-level view is absent. Role defaults remain only for legacy users without assignment scoping.
